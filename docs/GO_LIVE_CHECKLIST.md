# 오픈(라이브 전환) 체크리스트

목표 오픈일은 **10/29(목)**이다(계획서 단계 4). 항목마다 담당자와 완료일을 적는다.

## A. 서버와 도메인 — 10/23까지

절차는 `docs/DEPLOY_AWS.md`(AWS Lightsail, 단계별)와 `docs/DEPLOYMENT.md` 2장을 따른다.

- [ ] 작업 브랜치를 검토해 `main`으로 합친다(서버는 `main`을 받는다). 필요하면 `v1.0.0` 태그를 만든다.
- [ ] 운영 서버를 만든다(1장 권장 구성). 클라우드 방화벽은 22(관리자 IP만), 80, 443만 연다.
- [ ] `sudo bash setup-server.sh <저장소 주소> main`을 실행한다.
  - 시간대, 자동 보안 업데이트, 방화벽, Docker, `.env` 생성, 백업 cron까지 한 번에 된다.
- [ ] 자동 생성된 `APP_ENCRYPTION_KEY`를 서버 밖 안전한 곳(비밀번호 관리자 등)에 보관한다. `.env` 전체도 보관한다.
- [ ] 대관 도메인(예: `rent.taeil.org`)의 DNS A 레코드를 서버 IP로 지정한다.
- [ ] `deploy/.env`의 `SITE_DOMAIN`, `ACME_EMAIL`, `APP_BASE_URL`, `EMAIL_FROM`, `SMTP_USER`·`SMTP_PASS`, `BACKUP_S3_*`를 채운다(AWS는 `docs/DEPLOY_AWS.md` 7장).
- [ ] `./deploy.sh`로 배포한다.
  - [ ] `https://<도메인>/api/health`가 `{"ok":true}`를 돌려준다.
  - [ ] 브라우저 주소창에 자물쇠가 표시된다.
- [ ] `db:seed`를 실행한 뒤 공간 정보(이름, 정원, 사진, 공개 여부)를 확인한다.
- [ ] 첫 최고 관리자를 `admin:create --grade super`로 만들고 2단계 인증을 등록한다.
  - 나머지 계정(두 번째 최고 관리자, 내부 임직원, 동아리 운영자)은 **계정 관리** 화면에서 만든다.
  - 기본 등급의 권한이 기념관 운영 방식에 맞는지 **등급 관리**에서 확인한다.
  - 모든 관리자 계정에 이메일을 등록한다(계정 관리 또는 각자 **내 계정**). 그래야 아이디 찾기·비밀번호 재설정을 쓸 수 있다. `preflight`가 이메일 없는 계정을 경고한다.
  - 한 사람이 로그인 화면의 **비밀번호 재설정**으로 메일을 받아 링크가 운영 도메인(`APP_BASE_URL`)으로 열리는지 확인한다.
- [ ] `backup.sh`를 수동으로 한 번 실행한다. 파일이 생기고, 설정했다면 Object Storage에도 올라가는지 확인한다.
- [ ] **복구 연습**: 그 백업으로 `restore.sh`를 실행해 본다. 오픈 전, 실제 신청이 없을 때 한다.
- [ ] 가동 감시(UptimeRobot 등)에 `/api/health`를 등록하고 알림 받을 연락처를 넣는다.
- [ ] `pnpm preflight --smtp`에 오류(✗)가 없다. 경고(!)도 가능한 한 정리한다.

## C-1. 계좌이체 운영 점검 — 오픈 전

PG 없이 계좌이체로 오픈한다. 실제 계좌로 아래를 한 번씩 해 본다.

| # | 흐름 | 확인할 것 | 결과 |
|---|---|---|---|
| 1 | 신청 → 입금 안내 | 신청 완료 화면과 메일에 입금 계좌, 금액, 기한, "입금자명에 신청번호"가 보인다. 화면의 **계좌번호 복사**를 눌러 휴대전화 은행 앱에 붙여 넣어 본다. 담당자 주소로 "입금 확인 필요" 메일이 온다 | |
| 2 | 입금 → 입금 확인(함께 승인) | 소액을 실제로 입금한다. 관리자 화면 **신청 관리 → 입금 대기**에서 신청을 열고 "입금 확인과 함께 승인"으로 처리한다. 신청자에게 확정 메일이 오고 캘린더에 표시된다 | |
| 3 | 입금 → 입금 확인 → 반려 → 환불 | **환불 처리** 목록에 "요청"이 생긴다. 이체 후 환불 처리 내용을 적고 완료로 기록하면 환불 완료 메일이 간다 | |
| 4 | 입금 안 함 | 기한 3시간 전에 임박 메일이 온다. 기한이 지나면 자동 취소 메일이 오고 달력의 시간이 다시 열린다(테스트할 때는 입금 기한을 1시간 등으로 짧게 바꿨다가 되돌린다) | |

## D. 결제 라이브 전환 — PG 연동을 붙이기로 할 때 (오픈 후 별도 일정)

> 지금은 계좌이체로 운영한다. 아래는 PG 계약·연동을 진행할 때 따른다. 결제 방식을 PG로 바꾸기 전까지 신청자는 계좌이체 안내만 본다.

1. [ ] PortOne 콘솔에서 **실연동 채널**을 만든다. 계약한 PG사를 연결하고 결제 수단은 카드(필요하면 계좌이체)로 둔다.
2. [ ] `.env`에 라이브 값 4개(`PORTONE_STORE_ID`, `PORTONE_CHANNEL_KEY`, `PORTONE_API_SECRET`, `PORTONE_WEBHOOK_SECRET`)와 `PORTONE_MODE=live`를 넣는다. `PAYMENT_FAKE`는 **비워 둔다**.
3. [ ] PortOne 콘솔에 웹훅 주소 `https://<도메인>/api/webhooks/portone`을 등록한다.
4. [ ] 앱을 다시 시작한다.
   ```
   $C up -d --force-recreate web worker
   ```
5. [ ] 관리자 **정책 설정 → 연동 상태**에서 온라인 결제가 "설정됨 · 라이브"로 나오는지 확인한다.
6. [ ] (소액 테스트용) 요금표를 **예약 적용**으로 잠시 1,000원으로 바꾼다.
   - 테스트가 끝나면 원래 요금으로 되돌린다.
   - 테스트 신청 건에는 신청 당시 요금이 저장되므로 실제 신청에는 영향이 없다.

### D-1. 실결제 소액 테스트 (계획서 4-1)

실제 카드로 3가지 흐름을 확인한다. 테스트 신청은 기념관 담당자 명의로 한다.

| # | 흐름 | 확인할 것 | 결과 |
|---|---|---|---|
| 1 | 신청 → 결제 → **승인** | 결제 직후 "신청접수"로 바뀐다. 접수 메일과 확정 메일이 온다. PortOne 콘솔에 결제가 "결제완료"로 보인다 | |
| 2 | 신청 → 결제 → **반려** | 반려 메일이 온다. 신청 상세의 환불 내역이 "환불 완료"다. PortOne 콘솔에서 "취소"로 보인다. **카드사 취소 문자**가 온다 | |
| 3 | 신청 → 결제 → **철회**(나의 대관) | 철회 환불률만큼 환불된다. 100%가 아니면 **부분 취소**로 보인다 | |
| 4 | 결제창을 열었다가 닫기 | 신청이 "결제 대기"로 남는다. 결제 유효시간이 지나면 자동 취소되고 달력의 시간이 풀린다 | |
| 5 | (선택) 모바일에서 결제 | 휴대전화 브라우저로 1번을 반복한다. 결제 후 신청 화면으로 돌아온다 | |

- [ ] 모든 테스트 결제가 취소(환불)되었는지 PortOne 콘솔과 카드 명세에서 확인한다.
- [ ] 테스트용 요금을 원래 요금으로 되돌린다. **정책 설정 → 변경 이력**에서 확인한다.
- [ ] 브라우저 개발자 도구 콘솔에 `Content Security Policy` 경고가 없는지 확인한다. 결제창이 막히면 `next.config.ts`의 CSP를 조정한다.

## F. taeil.org 연결 — 10/28 (계획서 4-4)

taeil.org의 대관 안내 페이지에 신청 버튼을 추가한다. 홈페이지 편집기에서 HTML을 넣을 수 있으면 아래 코드를 쓴다. 넣을 수 없으면 링크 주소만 전달한다.

```html
<p style="margin:24px 0;text-align:center">
  <a href="https://rent.taeil.org/"
     style="display:inline-block;padding:14px 28px;border-radius:8px;background:#c8102e;color:#fff;font-weight:700;text-decoration:none">
    온라인 대관 신청하기
  </a>
</p>
<p style="text-align:center;color:#555;font-size:14px">
  공간별 빈 시간 확인, 신청, 결제, 신청 내역 조회를 온라인으로 할 수 있습니다.<br>
  문의 02-318-0903~4
</p>
```

- 버튼 색은 디자인 시안의 강조색에 맞춰 조정한다.
- 공간별로 바로 신청하게 하려면 링크를 `https://rent.taeil.org/spaces`로 둔다.
- [ ] 기존 대관 신청 방법(이메일·전화 접수)을 안내하는 문구를 온라인 신청 안내로 바꾼다.
