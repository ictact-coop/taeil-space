# 관리자 운영 매뉴얼

전태일기념관 대관 시스템의 관리자(최고 관리자, 내부 임직원, 동아리 운영자 등)를 위한 안내다.
관리자 화면 주소는 `https://<대관 도메인>/admin`이다.

## 1. 계정과 로그인

관리자는 **등급**에 따라 할 수 있는 일이 다르다. 기본 등급은 셋이고, 최고 관리자가 **등급 관리**에서 권한을 바꾸거나 새 등급을 만들 수 있다(1.2).

| 기본 등급 | 할 수 있는 일 (기본값) |
|---|---|
| **시스템 최고 관리자** | 모든 기능. 정책 설정 전체, 계정·등급 관리, 감사 로그. 나중에 생기는 기능도 자동으로 포함 |
| **기념관 내부 임직원** | 신청 조회·심사(보완요청·반려·승인·입금 확인), 환불 처리, 대관 캘린더, 휴관일·일정 차단·교육실 접수기간 관리, 정책 설정 조회 |
| **동아리 운영자** | 대관 일정 확인만 (**고정**). 캘린더에서 시간·공간과 예약 여부만 보이고 단체명·신청자 정보는 보이지 않는다 |

메뉴는 등급에 있는 권한만큼만 보인다. 권한이 없는 화면 주소로 들어가면 대시보드로 돌아가고 "권한이 없습니다"가 표시된다.

- **첫 로그인**: 임시 비밀번호로 들어가면 2단계 인증 등록 화면이 나온다.
  - 휴대전화의 OTP 앱(Google Authenticator, Microsoft Authenticator, 네이버 앱 등)으로 QR을 찍는다.
  - 앱에 나온 6자리 코드를 입력한다.
- **로그인할 때마다**: 비밀번호를 입력한 뒤 OTP 앱의 6자리 코드를 입력한다.
- **잠금**: 비밀번호나 코드가 5번 틀리면 잠시 잠긴다. 잠금 해제 시각이 화면에 나온다.
- **내 비밀번호 바꾸기**: 왼쪽 아래 이름 밑의 **내 계정**에서 바꾼다. 임시 비밀번호를 받았다면 첫 로그인 후 바로 바꾼다. 바꾸면 다른 기기의 로그인은 끊긴다.
- **내 이메일 등록**: **내 계정**에서 이메일을 등록한다(현재 비밀번호 확인). 아이디·비밀번호를 잊었을 때 이 주소로 안내를 받는다. 등록하지 않으면 계정 관리 담당자에게 요청해야 한다.
- **아이디를 잊었다**: 로그인 화면 아래 **아이디 찾기**에 등록한 이메일을 넣으면 그 주소로 아이디가 온다.
- **비밀번호를 잊었다**: 로그인 화면 아래 **비밀번호 재설정**에 아이디와 등록 이메일을 넣으면 재설정 링크가 온다.
  - 링크는 **30분 동안 한 번만** 쓸 수 있다. 계정당 한 시간에 3통까지 보낸다.
  - 새 비밀번호를 정하면 잠금이 풀리고, 다른 기기의 로그인은 모두 끊긴다.
  - 로그인할 때는 여전히 OTP 코드가 필요하다. OTP 기기를 잃어버렸다면 계정 관리 담당자에게 **2단계 인증 초기화**를 요청한다.
  - 화면은 계정이 있든 없든 같은 안내만 보여 준다(남이 계정 유무를 알아낼 수 없게). 메일이 오지 않으면 스팸함을 보고, 그래도 없으면 등록 이메일이 맞는지 계정 관리 담당자에게 확인한다.
- **세션**: 오래 쓰지 않으면 자동으로 로그아웃된다. 공용 PC에서는 반드시 **로그아웃**한다.

### 1.1 계정 관리 (계정 관리 권한)

**계정 관리** 메뉴에서 관리자 계정을 다룬다.

| 하려는 일 | 방법 |
|---|---|
| 새 담당자 계정 | 목록 아래 **새 계정**에 아이디, 이름, 이메일, 등급을 넣는다. 이메일은 선택이지만 넣어 두면 본인이 아이디·비밀번호를 스스로 찾을 수 있다. 임시 비밀번호가 **한 번만** 표시되니 직접 전달한다(메일·메신저에 남기지 않는다) |
| 등급·이름·이메일 변경 | 목록에서 아이디를 눌러 상세로 가서 바꾼다. 이메일을 바꾸면 이전 주소로 보낸 재설정 링크는 쓸 수 없게 된다. 등급을 바꾸면 그 계정은 다시 로그인해야 한다 |
| 비밀번호를 잊었다 | 이메일이 등록돼 있으면 본인이 로그인 화면의 **비밀번호 재설정**을 쓴다. 이메일이 없거나 메일을 받을 수 없으면 상세 → **임시 비밀번호 발급**. 잠금도 풀린다 |
| 휴대전화를 바꿨거나 잃어버렸다 | 상세 → **2단계 인증 초기화**. 본인인지 확인한 뒤 한다. 다음 로그인 때 OTP 앱을 다시 등록한다 |
| 퇴사·담당 변경 | 상세 → **계정 중지**. 계정을 지우지 않으므로 처리 이력과 감사 로그는 그대로 남는다. 다시 쓰려면 **사용 재개** |

- 목록의 **OTP 미등록**은 아직 첫 로그인을 하지 않은 계정, **이메일 없음**은 아이디·비밀번호를 스스로 찾을 수 없는 계정, **잠김**은 비밀번호·코드를 5번 틀린 계정이다.
- 잠금 방지 규칙
  - 자기 계정의 등급 변경, 초기화, 중지는 할 수 없다. 다른 관리자에게 요청한다.
  - 최고 관리자 등급을 주거나 빼는 일, 최고 관리자 계정의 초기화·중지는 최고 관리자만 한다.
  - 사용 중인 최고 관리자가 한 명도 남지 않게 되는 변경은 막힌다. 최고 관리자는 **두 명 이상** 두는 것을 권한다.
- 모든 변경은 감사 로그에 남고, 조치한 계정의 로그인은 즉시 끊긴다.
- **비상 복구**: 최고 관리자가 모두 로그인할 수 없으면 서버 담당자가 명령으로 복구한다.

```bash
# 서버의 /srv/taeil/deploy 에서 (C는 docs/DEPLOYMENT.md 2.3의 compose 명령)
$C run --rm web pnpm admin:manage list                          # 계정 목록·상태
$C run --rm web pnpm admin:manage reset-2fa --login admin       # OTP 다시 등록
$C run --rm web pnpm admin:manage reset-password --login admin  # 임시 비밀번호 발급, 잠금 해제
$C run --rm web pnpm admin:manage activate --login admin        # 중지된 계정 다시 사용
```

### 1.2 등급 관리 (최고 관리자)

**등급 관리** 메뉴에서 등급과 등급별 권한을 정한다. 최고 관리자만 보인다.

| 권한 | 할 수 있는 일 |
|---|---|
| 신청 조회 | 신청 목록·상세, 첨부 내려받기 (신청자 개인정보 열람) |
| 신청 심사 | 검토 시작·보완 요청·반려·승인, 계좌이체 입금 확인, 내부 메모 |
| 환불 처리 | 환불 목록, 계좌이체 환불 완료 기록, PG 환불 재시도 |
| 대관 일정 조회 | 대관 캘린더, 대시보드의 오늘 일정 (신청 조회 권한이 없으면 단체명만 보이고 상세로 들어갈 수 없다) |
| 휴관일·일정 관리 | 휴관일, 일정 차단, 교육실 접수기간과 그 설정값 |
| 정책 설정 조회 | 정책 설정 화면 보기 |
| 운영 정책 변경 | 운영 기본·신청 규칙·결제·환불·알림·개인정보·안내 문구 설정값 |
| 공간 관리 | 공간 정보·정원·사진·공개 여부 |
| 요금·감면 관리 | 요금표, 감면 종류 |
| 계정 관리 | 계정 생성·등급 지정·초기화·중지 (최고 관리자 계정은 제외) |
| 감사 로그 조회 | 로그인·설정 변경·개인정보 열람 기록 |

- **새 등급**: 이름, 설명, 권한을 고른다. 예: "자원활동가" = 신청 조회만.
  - 심사·환불 권한을 고르면 신청 조회 권한이 함께 들어간다.
  - 정책 관련 변경 권한을 고르면 정책 설정 조회 권한이 함께 들어간다.
- **권한 변경**: 저장하면 그 등급의 모든 계정에 바로(다음 화면부터) 적용된다.
- **최고 관리자 등급**: 이름과 설명만 바꿀 수 있다. 권한은 항상 "모든 권한"이고 지울 수 없다.
- **등급 삭제**: 그 등급을 쓰는 계정(중지된 계정 포함)이 없어야 지울 수 있다. 먼저 계정 관리에서 다른 등급으로 옮긴다.
- 등급을 만들고 고치고 지운 기록은 감사 로그에 남는다.
- **동아리 운영자 등급**: 권한이 "대관 일정 조회"로 고정되어 바꿀 수 없다(이름·설명만 수정). 기관 밖 사람이 신청자 개인정보를 보지 않도록 하기 위해서다.
- **개인정보 주의**: 기념관 밖 사람에게 다른 권한이 필요하면 새 등급을 만든다. "신청 조회" 권한을 주면 다른 단체 신청자의 이름·연락처를 볼 수 있으니 꼭 필요할 때만 준다.
- "신청 조회" 권한이 없는 등급은 캘린더·대시보드에서 단체명과 행사명 대신 "예약", "신청 진행 중"만 본다.

## 2. 하루 업무 흐름

1. **대시보드**에서 신규 신청, 입금·결제 대기, 보완 대기, 환불 실패, 오늘 이용 일정을 본다.
2. **입금 확인** (계좌이체로 운영하는 동안): 통장 입금 내역과 **신청 관리 → 입금 대기** 목록을 맞춰 본다(3.0).
3. **신청 관리**의 탭은 **입금 대기 · 예약 확정 · 반려 · 전체**다.
   - 입금은 확인했지만 아직 승인하지 않았거나 보완 중인 신청이 있으면 **확인 필요** 탭이 함께 보인다. 오래된 신청부터 연다.
   - 예약 확정 탭에는 이용완료와 취소 요청 중인 건도 들어 있다.
4. 신청 상세에서 심사한다(아래 3장).
5. **환불 처리**에 실패·수동 처리 건이 있으면 처리한다(아래 4장).
6. **대관 캘린더**에서 이번 달 확정 예약과 일정 차단을 확인한다.

## 3. 신청 심사

신청자가 신청서를 내고 결제(입금)가 확인되면 **신청접수** 상태가 된다. 기한 안에 결제(입금)되지 않은 신청은 자동으로 취소되고, 잡아 두었던 시간이 풀린다.

### 3.0 계좌이체 입금 확인 (PG 연동 전 기본 방식)

PG(카드 결제)를 붙이기 전까지는 **계좌이체**로 받는다. 흐름은 다음과 같다.

1. 신청자가 신청서를 내면 상태가 **결제대기**가 된다. 신청한 시간은 **입금 기한**(정책 설정, 기본 24시간)까지 다른 사람이 고를 수 없게 잡아 둔다.
2. 신청자에게 **입금 안내 메일**이 간다: 입금 계좌, 금액, 기한, "입금자명에 신청번호" 안내. 같은 내용이 신청 완료 화면과 나의 대관에도 보인다.
3. **담당자 알림 수신 주소**(정책 설정 → 알림)로 "새 대관 신청(입금 확인 필요)" 메일이 간다.
4. 기한 3시간 전(설정 가능)까지 입금 확인이 안 되면 신청자에게 **입금 기한 임박 메일**이 한 번 간다.
5. 담당자는 통장에서 입금(금액, 입금자명의 신청번호)을 확인하고 신청 상세의 **입금 확인**을 누른다. 입금자명·입금일시는 선택 입력이다. 적으면 처리 이력에 남는다.
   - **"입금 확인과 함께 승인" 체크**: 신청 내용을 이미 검토했다면 체크한다. 바로 **예약확정**이 되고 확정 메일이 간다.
   - **체크하지 않으면**: **신청접수**가 되고 접수 메일이 간다. 이후 검토하고 승인한다.
6. 기한 안에 입금이 확인되지 않으면 자동 취소되고 일정이 풀린다(신청자에게 메일).
   - 기한이 지난 뒤 입금된 돈은 시스템이 알 수 없다. 담당자가 직접 돌려주고 신청 상세에 메모를 남긴다.

- 입금 계좌·기한은 **정책 설정 → 결제·환불**에서 바꾼다. 입금 계좌는 오픈 전 필수 항목이다.
- 결제 방식을 "온라인 결제(PG)"로 바꾸는 것은 서버에 PortOne 키를 설정한 뒤에만 가능하다(그전에는 저장이 거부된다).

### 3.1 상세 화면에서 볼 것

- **자동검증**: 일정 중복, 휴관일, 최소 인원(공연장), 단체 제한(같은 단체의 월 이용 횟수 등) 검사 결과. 통과하지 못한 항목이 빨간색으로 표시된다.
  - 정원을 넘는 인원도 신청할 수 있다(2026-10 결정). 정원을 넘으면 예상 인원 옆에 **정원 초과** 표시가 나오니 운영 가능 여부를 확인한다.
- 신청서에는 행사 공개 여부를 묻지 않는다. 행사 목적·내용은 필수지만 글자 수 제한은 없다.
- **같은 단체번호의 다른 신청**: 사업자등록번호나 고유번호가 같은 이전 신청.
  - 단체번호를 적지 않은 신청은 "중복 여부 수동 확인"으로 표시된다. 단체 이름과 연락처로 확인한다.
- **첨부파일**: 행사계획서, 감면 증빙.
  - 내려받은 기록은 감사 로그에 남는다.
  - 파일마다 악성코드 검사 결과가 표시된다. "검사 안 됨"이면 열기 전에 PC 백신으로 검사한다.
- **감면 신청**: 증빙을 확인한다. 인정되지 않으면 보완을 요청하거나 반려한다.
- **금액·결제·환불**: 결제 금액, 결제 시도 내역, 환불 내역.
- **처리 이력, 알림**: 누가 언제 무엇을 했는지, 신청자에게 어떤 메일이 나갔는지.

### 3.2 처리 버튼

| 버튼 | 언제 | 결과 |
|---|---|---|
| **검토 시작** | 심사를 시작할 때 | 상태가 "검토중"으로 바뀐다. 다른 담당자와 겹치지 않게 표시하는 용도다 |
| **보완 요청** | 서류가 모자라거나 내용을 고쳐야 할 때 | 보완 내용을 적으면 신청자에게 메일이 간다. 신청자는 "나의 대관"에서 고쳐 다시 낸다. **보완 제출 기한**(정책 설정)이 지나면 자동으로 종료되고 전액 환불된다 |
| **반려 (전액 환불)** | 대관이 불가할 때 | 사유를 적으면 반려 메일이 가고 전액 환불이 요청된다(카드는 자동, 계좌이체는 담당자가 이체 후 완료 기록 — 4장). 잡혀 있던 시간은 풀린다 |
| **승인 → 예약확정** | 문제가 없을 때 | 예약이 확정되고 확정 메일이 간다. 캘린더에 표시된다 |
| **입금 확인** | 결제 방식이 계좌이체일 때(결제대기 상태) | 통장 입금을 확인한 뒤 누른다. 신청접수가 되고, "함께 승인"을 체크하면 바로 예약확정이 된다(3.0) |
| **내부 메모** | 언제든 | 담당자끼리만 보는 메모. 신청자에게는 보이지 않는다 |

- 반려 사유와 보완 요청 내용은 **신청자에게 그대로 보인다**. 정중하고 구체적으로 쓴다.
- 처리한 모든 일은 처리 이력과 감사 로그에 남는다. 지우거나 고칠 수 없다.

### 3.3 신청자가 할 수 있는 일

- **나의 대관**: 신청할 때 적은 이메일로 확인 코드를 받아 들어온다. 신청 목록, 상세 내용, 처리 이력을 본다.
- **보완 제출**: 보완 요청을 받은 신청을 고쳐 다시 낸다.
- **철회**: 승인 전에만 할 수 있다. 정책 설정의 "승인 전 철회 환불률"만큼 자동으로 환불된다.
- **확정 후 취소**: 아직 화면이 없다(오픈 후 2주 안에 추가 예정, 계획서 5-1). 그때까지는 아래 절차로 처리한다.
  1. 전화나 메일로 취소 요청을 받는다.
  2. 정책 설정의 "확정 후 취소 시점별 환불률"로 환불액을 계산한다.
  3. 계좌이체로 받은 신청은 그 금액을 신청자 계좌로 이체한다. 카드(PG)로 받은 신청은 **PortOne 관리자 콘솔**에서 부분 취소한다.
  4. 신청 상세의 **내부 메모**에 처리 내용을 남긴다.

## 4. 환불

- **환불이 생기는 경우**: 반려, 보완기한 만료, 승인 전 철회. 카드(PG) 결제는 시스템이 자동으로 환불한다(기한 후 결제·금액 불일치도 자동 환불).
- **계좌이체로 받은 신청은 환불도 담당자가 한다**: **환불 처리** 목록에 "요청" 상태로 올라온다(아래).
- **환불 실패**: PG 환불이 5번 실패하면 **환불 처리** 목록에 "실패"로 올라온다. 신청 상세의 환불 내역에서 **다시 시도**를 누른다.
  - 계속 실패하면 PortOne 콘솔에서 결제 상태를 확인한다. 이미 취소되어 있으면 수동 완료로 기록한다.
- **계좌이체 환불**: 결제 방식이 계좌이체면 환불도 담당자가 직접 한다.
  1. 신청자의 환불 계좌로 이체한다.
  2. 환불 내역의 **환불 처리 내용**에 "○○은행 이체, 10/30"처럼 적고 완료로 기록한다.

## 5. 정책 설정

**정책 설정** 메뉴에서 운영 규칙 대부분을 코드 수정 없이 바꿀 수 있다.

| 메뉴 | 내용 | 수정에 필요한 권한 |
|---|---|---|
| 개요·오픈 준비 | 오픈 전에 반드시 확정할 항목 점검, 예약 적용 대기 중인 변경 | 항목별 권한 |
| 운영 기본 | 유료 대관 전환일, 대관 시간, 야간 대관(토·일요일 야간 여부 포함, 기본은 받지 않음), 동절기, 예상 심사기간 안내 | 운영 정책 변경 |
| 공간 | 공간 이름, 정원, 사진, 공개 여부 | 공간 관리 |
| 휴관일 | 정기 휴관(매주 월요일 등), 공휴일, 임시 휴관 | 휴관일·일정 관리 |
| 일정 차단 | 기념관 자체 행사, 공사 등으로 특정 시간을 막기 | 휴관일·일정 관리 |
| 교육실 접수기간 | 접수를 여는 기간 | 휴관일·일정 관리 |
| 신청 규칙 | 신청 가능 기간, 최소·최대 이용 시간, 단체 제한 | 운영 정책 변경 |
| 요금표 | 공간별 기본요금, 추가요금, 야간요금, 부대시설 | 요금·감면 관리 |
| 감면 | 감면 종류, 감면율, 필요한 증빙 | 요금·감면 관리 |
| 결제·환불 | 결제 방식(온라인·계좌이체), 결제 유효시간, 입금 계좌, 철회·취소 환불률 | 운영 정책 변경 |
| 알림 | 입금 기한 임박 알림, 이용 전 안내 시점 | 운영 정책 변경 |
| 개인정보 | 보존 기간 등 | 운영 정책 변경 |
| 안내·규정 문구 | 이용자 화면의 안내문, 동의 문구 | 운영 정책 변경 |
| 연동 상태 | 결제, 메일, 문자, 파일 저장소 설정 여부(읽기 전용) | — |

- **적용 시각**
  - 바꾼 값은 "지금 바로" 적용하거나 날짜를 정해 예약할 수 있다. 예: 요금 인상을 1월 1일부터 적용.
  - 예약한 변경은 적용 전까지 취소할 수 있다.
- **이미 들어온 신청은 그대로**
  - 신청 건마다 신청 당시의 요금과 정책이 저장된다.
  - 요금이나 환불률을 바꿔도 기존 신청에는 영향이 없다.
- **이력**
  - 모든 변경은 **변경 이력**에 남는다(누가, 언제, 이전 값, 새 값, 사유).
  - 되돌리려면 이전 값으로 다시 저장한다.

## 6. 감사 로그

**감사 로그**에서 다음 기록을 기간, 담당자, 대상별로 검색할 수 있다.

- 관리자 로그인
- 설정 변경
- 신청 상세 조회
- 첨부 내려받기
- 심사 처리
- 환불

개인정보 열람 기록을 확인할 때 쓴다. 기록은 지우거나 고칠 수 없다.

## 7. 문제가 생겼을 때

| 증상 | 확인할 것 | 연락 |
|---|---|---|
| 사이트가 열리지 않는다 | `https://<도메인>/api/health`가 열리는지 | 시스템 관리자(서버) |
| 신청자가 입금했다는데 신청이 "결제대기"로 남아 있다 | 계좌이체는 담당자가 **입금 확인**을 눌러야 접수된다(3.0). 통장 내역을 확인한다. (카드 결제라면 5분 안에 자동 반영되고, 10분이 지나도 그대로면 PortOne 콘솔을 확인한다) | 대관 담당 |
| 입금 기한이 지난 뒤 입금됐다 | 신청은 이미 자동 취소되었다. 일정이 비어 있으면 신청자에게 다시 신청하도록 안내하고 입금액은 돌려준다. 신청 상세에 메모를 남긴다 | 대관 담당 |

## 8. 통계 (통계 조회 권한)

왼쪽 메뉴 **통계**에서 대관 실적을 봅니다. 기본 등급 중에서는 최고 관리자와 내부 임직원이 볼 수 있습니다(동아리 운영자는 볼 수 없음).

- **월별**: 연도를 고르면 1~12월 실적이 나옵니다.
- **주별**: 연도와 월을 고르면 그 달의 주별 실적이 나옵니다.
  - 주는 월요일에 시작합니다. 달을 걸치는 주는 목요일이 있는 달에 넣습니다. 예를 들어 9/28~10/4는 10월 1주입니다.
- **CSV 내려받기**: 화면의 표를 엑셀에서 바로 열 수 있는 파일로 받습니다. 공간별 건수와 시간이 열로 붙습니다.

| 표 | 기준일 | 세는 것 |
|---|---|---|
| 이용 실적 | 이용일 | 일정이 확정된 대관(예약확정·취소 요청 중·이용완료). 건수, 이용시간(준비·철수 제외), 예상 인원, 무료 건수. 공간별로 나눠 보여 줍니다 |
| 접수 실적 | 신청서 제출일 | 신청 건수와 지금 상태(진행 중·확정·반려·철회/취소) |
| 수입 | 입금 확인·결제일 / 환불 완료일 | 받은 금액, 돌려준 금액, 순수입 |

- 숫자는 화면을 열 때마다 새로 계산합니다. 지난 달 숫자도 나중에 취소·환불이 생기면 바뀔 수 있습니다. 보고용 숫자는 CSV로 받아 보관합니다.
- 기념관에서 쓰는 통계 양식을 주시면 같은 모양으로 나오게 추가합니다.
