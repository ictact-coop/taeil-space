# 오픈을 위해 기념관에 요청할 것

아래 항목이 모이면 라이브 전환을 진행할 수 있다(`docs/GO_LIVE_CHECKLIST.md`).
비밀 값(키, 비밀번호)은 **메일이나 메신저에 평문으로 보내지 말고**, 비밀번호 관리자 공유 기능을 쓰거나 서버 담당자가 직접 입력한다.

| # | 항목 | 내용 | 필요한 시점 | 비고 |
|---|---|---|---|---|
| 1 | **입금 계좌** | 대관료를 받을 계좌(은행, 계좌번호, 예금주)와 입금 확인 담당자 | 10/23 | PG 없이 계좌이체로 오픈한다. 담당자가 통장 입금을 확인한 뒤 관리자 화면에서 '입금 확인'(필요하면 함께 승인)을 누른다 |
| 2 | **운영 서버 결정과 계정** | 클라우드 계정(권장: 네이버클라우드) 개설, 결제 수단 등록, 서버 담당자 접속 권한 | 10/20 | `docs/DEPLOYMENT.md` 1장. 기념관 명의로 개설해야 담당자가 바뀌어도 소유가 유지된다 |
| 3 | **도메인** | 대관 사이트 주소(예: `rent.taeil.org`)와 DNS 레코드를 추가할 권한, 또는 DNS 담당자 연락처 | 10/20 | A 레코드 1개와 메일 인증(SPF·DKIM) 레코드 |
| 4 | **메일 발송 계정** | SMTP 주소, 계정, 비밀번호, 발신 주소(예: `rent@taeil.org`) | 10/23 | NCP Cloud Outbound Mailer, 기념관이 쓰는 메일 서비스(SMTP 지원 여부 확인) 등 |
| 5 | **오픈 전 필수 설정값** | 요금표, 입금 계좌·입금 기한, 환불률(철회, 확정 후 취소), 보완 제출 기한, 교육실 접수기간, 휴관일·행사 일정, 감면 기준, 유료 대관 전환일 | 10/26 | 담당자가 관리자 화면에서 직접 입력해도 된다. 오픈 준비 점검 화면에 남은 항목이 표시된다 |
| 6 | **안내·약관 문구 검토** | 이용 안내, 운영 규정, 환불 규정, 개인정보 수집·이용 동의 문구 | 10/26 | 개인정보 동의 문구는 기념관 개인정보 처리방침과 맞춘다 |
| 7 | **관리자 명단과 등급별 권한** | 관리자별 이름·아이디·등급(최고 관리자 / 내부 임직원 / 동아리 운영자 등), 기본 등급 권한 조정이나 추가 등급이 필요한지 | 10/23 | 계정마다 OTP 앱을 쓸 휴대전화가 필요하다. 최고 관리자는 두 명 이상 권장. 동아리 운영자는 일정 확인만 가능(결정됨) |
| 8 | **taeil.org 수정 담당자** | 대관 안내 페이지에 신청 버튼을 넣을 담당자(또는 홈페이지 업체) 연락처 | 10/27 | 버튼 코드는 체크리스트 F절에 있다 |
| 9 | **비상 연락망** | 대관, 회계, 서버, 유지보수 담당 연락처 | 10/27 | 운영 매뉴얼 7장 |
| 10 | (선택) 오류 알림 서비스 | Sentry 같은 오류 모니터링 계정 | 오픈 후 | 없어도 운영할 수 있다. 서버 로그와 가동 감시로 대신한다 |
| 11 | (단계 5) 문자 발송 | 발신번호 사전 등록(통신사 서류), 문자·알림톡 서비스 계정(NCP SENS 등) | 11월 초 | 이용 전 안내 문자에 필요 |
| 12 | (나중에) PG 결제 연동 | PortOne 가입·PG 계약 후 라이브 키 4개(Store ID, 채널 키, API Secret, 웹훅 시크릿) | PG를 붙이기로 할 때 | 받으면 체크리스트 D절대로 전환한다. 그전에는 계좌이체로 운영 |
